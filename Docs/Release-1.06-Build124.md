# 拾光号 iOS 正式版 1.06 Build124

基于正式 1.05 Build123（单中文后备字体）。新增「游戏资源增量更新」独立入口。

- 本地增量 ZIP 或共享 Import 文件夹导入，先显示源版本和目标版本、覆盖/新增数量，用户确认后才合并。
- 完整游戏资源先安装；仅允许新版核心增量，拒绝重复更新/降级、不支持的包结构。
- 严格路径、重复项、类型、文件数量/大小安全检查；CRC32 解压校验及安装后 SHA256 核验。
- 按文件备份（不拷贝几 GB 完整 Game 目录）、写盘事务日志；安装失败回滚，App 重启时恢复未提交事务。
- 资源安装后复检 Client.swf、地图、登录、核心文件；核心修订标记在最后更新。
- 与现有手机适配 .sgpatch 独立；资源版本更新后旧补丁仍受版本匹配保护。
- 保留基地 roomSocket 连接修复、每日签到路径兼容、鼠标、键盘、帧率和单中文字体。
- 此次用户提供的增量 ZIP 目标为 2026110401，包含 594 个文件，无完整 Client.swf。

注意：游戏增量包不是手机适配补丁，也不是完整 .srom。构建通过后仍需在真机上测试增量安装、重启及游戏各界面。
