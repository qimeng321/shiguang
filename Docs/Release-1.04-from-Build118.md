# 拾光号 iOS 正式版 1.04 · Build 120

## 代码基础与升级方式
- **基线**：测试版 `1.2 Build118` (`24fb830d9aec341bf6f5e354605148b85ecb6265`)，并非旧正式版1.03或 Build119；独立升级分支，不改现有 `main`。
- **正式版安装标识**：`cn.shiguanghao.launcher`；展示 `拾光号启动器`，内部 CFBundleShortVersionString `1.0.4`、CFBundleVersion `120`。
- 签名更新应沿用原正式版的同一个团队/安装方式，尽可能覆盖升级；卸载正式版会清掉私有完整资源。

## 删除智能悬停
- 完全删除长按、NoNo 专用自动悬停状态机、相关手势 fallback、重复指针监听、定时器、SwiftUI开关、注入脚本、崩溃自动激活与旧测试脚本。
- **精准鼠标仍在**：触控板点击、移动、双击、右键、拖动、速度；**普通触摸和触屏延迟模式**保留。

## 继承 Build118
- 保留 `.sgpatch` 手机补丁包导入与撤销覆盖层（可恢复原游戏资源），附加资源完整性核验与CRC导入保护。
- 保留 45 秒 / 40000 条已验证资源路径索引、条件 ETag/HTTP304 小图标缓存、诊断日志、桌面微端式直接启动与 WebSocket代理。
- 保留固定 Ruffle 比例布局、右上角滚动工具菜单、中文输入、画质与 30/60/不限帧率选项。
- 保持删除实验地图箭头，游戏原始星系地图不变。

## 新资源适配与限制
- 解析用户提供的 `Shiguang_iOS_NewResource_Analysis.zip`，其 206 个关键文件包含 `Client.swf`，SHA256与原PVM补丁签名完全一致。
- 已识别最新版 `0.18.0`、核心修订 `2026110304`；只在安装后资源检查中展示指纹和版本信息，不强制限制其他有效包。
- **分析ZIP不是原始完整约2.7GB资源包**，IPA不内嵌游戏数据；真机必须自行导入完整 `拾光号-美化整合包-2026110304.zip` / `.srom`。
- 没有实际服务端连接和真机游戏加载测试，未确认新游戏资源真实运行、NoNo页面和全量性能。
- 现有 `main` 正式版1.03与先前Build119分支均保持不变。

完整包导入、登录选服、NoNo精准鼠标功能、虚拟鼠标双击/右键、手机补丁导入清除、中文键盘、画质切换、FPS、资源请求缓存与后台/横竖屏稳定性。
