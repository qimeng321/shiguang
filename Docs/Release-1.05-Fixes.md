# 拾光号 iOS 正式版 1.05（Build 121）

以正式版 1.04 Build120 为基础，保持 `cn.shiguanghao.launcher` Bundle ID、游戏资源和 .sgpatch 导入机制。

1. 基地：新增 GET_ROOM_ADDRES (10002) 下行基地地址映射、独立虚拟端口 22975 和本地 WebSocket 32975；从服务器读取原始基地地址，不修改会话令牌。
2. 二次进入：共享桥接监听，退出清理活动连接但不抢占重建固定端口，关闭当前 HTTP 服务。
3. 每日签到：只修正日志证实的异常 `app//nonoPanel/NonoVipDailySignPanel.swf` 为合法单斜杠资源路径。
4. 菜单：右上角工具栏改为双列紧凑布局。
5. 字体：简体中文后备字形基线由 +35/1000 em 提升为 +60/1000 em，不移动 SWF 舞台或触控坐标。

此版本可在 CI 中执行 Swift 编译与静态验证。基地的真实服务器通信、每日签到完整点击路径以及字体的全部界面显示仍须真机联网复测，编译成功不等于全部实测通过。
