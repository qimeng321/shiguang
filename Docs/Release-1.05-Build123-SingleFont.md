# 拾光号 iOS 正式版 1.05 Build 123（单字体轻量版）

基于 1.05 Build 122 保留基地 Socket 代理、TCP 分帧、签到路径修复、紧凑菜单、精准鼠标和手机补丁系统。

**体积改进**：仅捆绑一套 Noto Sans CJK SC 正式后备字体；将原始 OTF 的字形基线在构建时提高 110/1000 em，直接覆盖这份字体。移除多余两份 OTF 和启动器字体档位选择。游戏 .srom、SWF 资源和用户数据均不改动。

版本号：1.0.5；构建号：123；正式包名：cn.shiguanghao.launcher。

构建与静态测试不等于真机所有地图、基地、字体效果通过，须继续根据游戏测试反馈核验。
