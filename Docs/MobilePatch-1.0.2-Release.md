## 使用

在 1.08 首页「手机适配补丁」选择 `.sgpatch` 导入，退出游戏重新进入。新补丁会**整体替换**旧手机补丁覆盖层，不是叠加安装。出现问题时点击「清除手机补丁」再重新进入游戏即可撤销；不会修改原始 SROM 资源。

已完成 ZIP CRC32、文件清单、源资源哈希和路径限制等离线检查；真机背包与命运之轮玩法需要独立测试。1.07 无法通过其手机补丁入口安装这份带核心的补丁。
