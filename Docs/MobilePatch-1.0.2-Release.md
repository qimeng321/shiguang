# 拾光号手机适配补丁 · 正式版 1.0.2（通用无版本锁）

发布日期：2026-11-13。适配启动器：**正式版 1.08 Build130**，或具备无锁核心覆盖能力的后续版本。

## 规则：基础功能包与游戏资源版本分离

补丁清单只有 `format`、`name`、`version`、`files`；明确**不设置** `targetRevision` 或 `originalSHA256`。以后资源包升级，不要求仅因版本号改变就重新打包手机补丁。若游戏核心结构实际改变并影响适配，将根据新的资源包进行针对性更新。

## 导入与撤销

在启动器首页「手机适配补丁」导入 `.sgpatch`；不会修改原 Game 文件，而是作为 HTTP 资源覆盖层启用。导入新补丁会替换原有覆盖层，退出游戏重新进入生效。异常时通过「撤销补丁」恢复原始资源。

**重要**：补丁不锁资源版本，不意味着任何未来核心都必定兼容；若新版游戏不再加载 `dll/SGCore.swf`，该核心覆盖可能不会生效。1.07 旧导入器不支持核心文件覆盖；1.08 Build129 旧导入器要求 SHA/修订锁，因此这份通用版应与 Build130 配套使用。静态和 ZIP 完整性校验已进行，真机背包回归仍需测试。
