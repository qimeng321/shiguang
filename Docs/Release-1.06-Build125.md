# 拾光号 iOS 正式版 1.06 · Build125（UI 与增量 SROM 支持）

在 1.06 Build124 基础上做小幅维护，正式版 Bundle ID 与营销版本 1.0.6 不变。

1. 游戏画质与最高帧率从 iOS 系统默认灰色 segmented Picker 改为自绘三项切换：当前项蓝底白字、其他项白底深色字，背景浅灰，点击后继续写入已有 AppStorage 设置，下一次进入游戏生效。
2. 移除「游戏资源增量更新」卡片上的“1.06 新功能”以及「手机适配补丁」卡片上的“测试功能”角标。
3. 游戏增量更新的文件选择与共享 Import 列表均同时支持 .zip / .srom。两者都只接受真正 ZIP 压缩内容；非 ZIP 格式 .srom 会说明不支持，绝不凭扩展名强行解码。
4. 新增完整游戏包识别提示：若内含 Client.swf、index.html、assets/ 或 login/ 等完整启动资源，不在增量入口合并，而是引导使用「导入美化包」。
5. **保留**原有：新版本检查、拒绝降级与重复更新、ZIP CRC32、增量资源路径/数量/大小检查、SHA-256 安装校验、按文件备份、持久事务日志、安装中止/重启回滚、手机补丁独立覆盖层与核心资源版本适配机制。

限制：300 MB 解压上限、2000 文件上限保持不变。非 ZIP 封装的 SROM 不支持。未更改游戏 SWF、Ruffle 引擎、网络代理、基地/签到/NoNo/字体或正式版包 ID。

本次提供可检查的 GitHub 源码分支；无 Mac/Xcode 本地构建结果，未生成 IPA，也未完成真机验证。
