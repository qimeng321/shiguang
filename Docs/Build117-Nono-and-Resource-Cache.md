# 拾光号 iOS 1.2 Build117（NoNo 圆环点选修复 + Windows 微端资源优化）

基线：Build 116。仅修改独立测试分支 test/1.2-nono-ring-click-win-optimization-b117，正式版 1.03 未改动。

### NoNo 圆环
- 保留已在 Build 116 真机成功出现的 420ms 长按悬停和持续 hover。
- 处理圆环按钮二次点击：鼠标先移动到图标，延迟 110ms 后按下，保持 190ms 再抬起，给 Flash/Ruffle 留出处理 hover / hitTest 的机会。
- 新增长按后拖动至圆环图标松手的触控捷径。
- 只在最近 8 秒且与长按 NoNo 中心距离 165 CSS 像素以内的二次点击使用延迟时序，其他按钮保持快速 65ms 点击，不影响正常战斗和背包。
- 取消模式、后台、关闭页面均释放未完成的定时器和鼠标按键。模拟测试验证了事件数量、顺序和时间边界。
- **真实圆环图标是否可点击仍需 iPhone 测试**；如果 SWF 内部逻辑在指针移动时隐藏菜单，可能需要专门的 SWF 资源补丁。

### 地图功能
- 完整删除新增的地图箭头、边缘悬停、拖拽替代、菜单控制和附加 JS；没有自动地图识别。**不删除原游戏自带星系地图和地图 SWF**。

### 借鉴 Windows 微端
- 新增每次游戏会话内的资源路径正向缓存，避免同一资源每次请求都做完整符号链接解析与 regular-file 校验。仅缓存经过路径安全检查且确实存在的普通文件。
- 缓存 45 秒后重新验证，最多 40,000 条；不缓存未找到的资源，支持移动端补丁覆盖顺序；诊断日志每约 1000–5000 次命中输出一次摘要。
- 保留 Build115 已有小图标 ETag / HTTP 304、慢文件准备记录、可撤销手机补丁、CRC32 导入校验与 FPS 显示。
- 缓存属于文件系统层的潜在优化，并不等于 Ruffle 帧率、GPU 或发热已改善；Windows 原生内核不能直接运行于 iOS。

### 重点真机测试
1. 开启智能悬停，长按 NoNo 约 0.42 秒，出现圆环后松手，再点各圆环图标。
2. 长按 NoNo 不松手，手指滑到圆环按钮后松手，观察按钮响应。
3. 在背包、对战、非 NoNo 场景检查短点是否正常，避免慢点击或误触。
4. 连续开关三点菜单和精准鼠标，确认画面仍不抖动。
5. 若失败，请导出 diagnostics.txt（不需要提供游戏密码），并描述“点了哪个图标、圆环是否消失”。
