# 拾光号 iOS 启动器 · 正式版 1.08（Build129）

发布时间：2026-11-13。由已成功通过 GitHub Actions 构建的 `test/shiguang-1.08-b129-wheelpatch` 分支正式化；正式发布分支为 `release/shiguang-1.0.8-b129`。本次未改动原有 1.07 正式版分支。

## 1.07 → 1.08 主要变化

- **正式版标识**：首页显示「正式版 1.08」，内部版本 `1.0.8`、Build129；应用标识依然是 `cn.shiguanghao.launcher`，沿用同一证书可覆盖安装并保留本地游戏资源（安装前仍建议备份）。
- **扩展手机补丁能力**：在原有仅限 `resource/` 的覆盖层基础上，允许补丁覆盖唯一核心路径 `dll/SGCore.swf`；**必须**满足游戏版本 `2026110801` 和原始核心 SHA-256 校验才能启用。其他 DLL、登录、配置、JS、Ruffle 文件依旧禁止覆盖。
- **原文件保护**：手机补丁为只读 HTTP 覆盖层，不改动已安装的 2.8GB 游戏资源；可在首页清除手机补丁恢复原始资源。
- **继承 1.07**：延续原有服务器地址、资源导入、增量更新、虚拟鼠标、帧率/画质选项、键盘、NoNo 与已有命运之轮资源路径处理。

## 相关手机适配补丁 1.0.2

与正式版 1.08 配套的 1.0.2 补丁同时包含 `resource/worldMap.swf`、`resource/taskIcon.swf` 与单独优化过背包套装交互的 `dll/SGCore.swf`。对比用户提供的 1.0.1 文件，前两项二进制不变，新加入核心适配。它**不包含**此前用于命运之轮的实验性回调及动画修改。

## 安装与风险

1. 确保当前游戏资源是 `2026110801`，备份旧版 IPA 与补丁。
2. 使用**同一签名证书**覆盖安装 1.08；不要卸载旧 App（卸载可能删除已导入资源）。
3. 首次启动先不加载补丁验证登录和进入游戏，再通过独立「手机适配补丁」入口导入 1.0.2。
4. 退出并重新进入游戏，重点检验背包套装点击、穿戴和其他游戏流程。
5. 如有异常，通过首页「清除手机补丁」撤销，重新进入游戏后恢复原始核心。

**说明**：本次升格属于发布标识与补丁权限的稳定化处理。GitHub Actions 构建成功不代表全部 iOS 机型与玩法均通过真机回归。命运之轮非战斗切层后卡牌不出现的问题，**不宣称已经修复**。1.0.2 补丁也不保证解决所有背包交互问题。
