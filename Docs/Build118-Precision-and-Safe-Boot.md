# 拾光号 iOS 1.2 Build 118 — NoNo精准点击与启动保护

基线 Build 117；独立测试标识 `cn.shiguanghao.launcher.smartbeta`。正式版 1.03 不受影响。

## 修复
- 依据真机反馈：精准鼠标能够进入 NoNo 圆环功能，但智能悬停点击圆环后关闭，故让智能悬停使用精准鼠标同一套 `pointermove → pointerdown → 125ms → pointerup` 机制。取消 Build117 的延迟110ms再按下及按住190ms。
- 圆环已出现后，第二次真实触摸**按下时不再提前移动游戏光标**，待触摸结束时发送精准鼠标点击事件，以减小圆环的 `MOUSE_OUT` 误关闭。
- 保留长按 NoNo 420ms 触发圆环、持续悬停、长按滑到图标后释放、TouchEvent 兜底、双击/右键和原生鼠标。
- 智能悬停开关在登录和资源加载阶段只记录“请求开启”，**不拦截触摸**；收到服务器进入游戏成功状态后，延迟3.5秒再开启。回到后台时暂停，返回前台时延迟恢复。
- 若 WKWebView WebContent 进程终止，自动将智能悬停保存设置改为关闭；不自动陷入重启循环，下次重新加载游戏优先原生触控。
- 延续 Windows 微端的路径正向缓存（45秒、4万条上限）、小图标 ETag/304、可撤销补丁和诊断；本次不改引擎或画质，避免混淆崩溃原因。

## 限制与验证
静态测试可确认触控顺序、冻结第二次触摸、按键时长、构建语法；**无法保证 NoNo 实际功能页在未装机前一定打开，也无法保证 WebKit 崩溃彻底消失**。若再次崩溃，请提供 diagnostics.txt，并可收集 iOS 设置/分析与改进中的 JetsamEvent。
