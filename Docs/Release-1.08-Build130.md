# 拾光号 iOS 启动器 · 正式版 1.08（Build130）

发布日期：2026-11-13；分支：`release/shiguang-1.0.8-b130-unlocked`。在正式版 1.08 Build129 基础上调整**手机补丁的版本校验策略**，其他原有功能保留。旧 Build129 和 1.07 发布分支不变。

## 两种互不关联的版本机制

1. **完整游戏资源包**：继续支持正常导入结构完整、通过必要文件校验的 ZIP/SROM 资源包。启动器从包内 `config/dll.xml`、`assets/index.js` 等实际配置解析核心路径和 WASM 路径，**不把完整包锁在 `2026110801`**。后续新版资源包只要符合启动器支持的打包结构就可导入；具体游戏运行兼容性仍需要验证。
2. **手机适配补丁**：独立的 `.sgpatch`/ZIP 覆盖层，不修改本地 Game 文件。1.0.2 通用补丁的清单**不包含 `targetRevision` 或 `originalSHA256`**，所以导入和游戏启动时不对资源包修订号及原版核心哈希作锁定；换用新版资源包后仍可尝试启用该补丁，无需重复制作绑定版本的安装包。

## 补丁机制

- 仍然只允许 `resource/` 内经过许可的素材以及明确的 `dll/SGCore.swf`；不允许任意 DLL、配置、JS、HTML、登录脚本或 Ruffle 引擎覆盖。
- 未锁定的补丁可以跨资源版本使用；旧版**明确带有** `targetRevision` 或 `originalSHA256` 的补丁仍按其显式声明校验，以免意外解除其他补丁作者设置的约束。
- 核心 SWF 的文件头与最小体积校验保留；ZIP 校验、路径安全和文件清单校验保留。
- 补丁与原资源包相互独立：在首页「手机适配补丁」导入，重新进入游戏生效；出现问题可撤销，恢复原始文件。
- 对使用 `dll/NieoCore.swf` 或其他不同核心路径的未来资源包，不能假定固定 `dll/SGCore.swf` 覆盖会自动命中；需进一步适配或等待用户提供更新信息。

## 1.0.2 通用补丁（与 1.0.1 比较）

保留 1.0.1 的 `resource/worldMap.swf`、`resource/taskIcon.swf`，新增背包套装交互优化 `dll/SGCore.swf`，不包括此前未验证的「命运之轮」实验修复。清单不带资源包修订号、原始核心 SHA-256。没有改变其中三份 SWF 的实际内容。

## 安装

1. **不要卸载旧版 App**。使用原签名证书覆盖安装 Build130，Bundle ID 继续为 `cn.shiguanghao.launcher`；覆盖安装可保留原先导入的游戏文件，但仍建议提前备份。
2. 检查能否正常登录，再从独立「手机适配补丁」入口导入通用 1.0.2，退出游戏并重新进入。
3. 更换完整 SROM 后仍可使用此通用补丁；如背包或其他玩法异常，先撤销补丁，确认原版正常后再报告实际资源版本。

**兼容性提醒**：取消版本和 SHA 锁的是**导入限制**，不是对未来未知 SWF 核心的功能兼容保证。核心实现即使文件名相同也可能变更。保留撤销入口的目的就是安全回退。离线构建与静态测试通过不等于 iOS 真机完整回归通过。
