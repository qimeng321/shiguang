# 拾光号 iOS 1.2 Build116 · 问题修复测试版

基于 Build115；正式版 1.03 未更改，测试版使用独立包标识。

- 游戏舞台锁定初始 innerWidth / innerHeight，禁止菜单、鼠标、键盘导致的 viewport 抖动触发重排；仅旋转后重新缩放。
- SwiftUI 游戏页面增加固定 GeometryReader 容器，取消展开工具菜单的布局动画。
- 智能悬停增加 TouchEvent-only 兜底和 420ms 长按后的连续 hover pulse，含触控清理和反馈日志。NoNo 圆环能否由 Ruffle 识别需真机验证。
- 地图箭头默认使用鼠标边缘悬停，单击悬停约 560ms，长按 350ms 后持续流动直至松手。三点菜单提供拖拽备用模式；游戏内另设关闭入口。
- 地图完整自动显示/隐藏仍取决于 SWF 地图界面向 ShiguangMapBridge 发事件；没有该事件时不进行不可靠的状态猜测，菜单手动打开测试。
- 登录栏提示改为“先点游戏中的账号或密码框，再点这里输入”，保留原有键盘输入。
- 保留 Build115 手机补丁覆盖层、HTTP缓存、慢请求日志等内容。

本地 Node 事件模拟及 Swift 语法解析通过，但不能代替真实 iPhone 上 NoNo 菜单和地图滚动验证。
